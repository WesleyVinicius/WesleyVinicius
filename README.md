## 🚀 Projetos em destaque

**📚 [Sistema Reler](https://github.com/WesleyVinicius/sebo-reler)**
- Sistema web em Laravel e PostgreSQL para gestão de um sebo.
- Cadastro de livros, estoque, autores e editoras, vendas e administração.
- Tecnologias: PHP, Laravel, PostgreSQL, Bootstrap.

**🤖 [Normalizador de metadados agrometeorológicos](https://github.com/WesleyVinicius/agro_metadata_normalizer)**
- API em FastAPI com uma rede neural MLP do Scikit-learn que sugere nomes padronizados para cabeçalhos de dados agrometeorológicos.
- Desenvolvida como parte do TCC da especialização em Desenvolvimento Web e Mobile.
- Tecnologias: Python, FastAPI, Scikit-learn, Pandas.

**🌾 [AgroMeta](https://github.com/WesleyVinicius/agrometa)**
- Projeto do mestrado sobre interoperabilidade entre padrões internacionais de metadados agrícolas e meteorológicos.
- Tecnologias: Python, FastAPI, RDF, SPARQL, OWL.
